# OSCP Prep

Personal OSCP-style notes: **templates**, **tool cheatsheets**, and **sanitized box writeups**.

This is my workflow — not OffSec course material. Exam notes are not here.

Lab IPs in **text** are replaced with `TARGET` (victim) and `ATTACKER` (Kali). Screenshots are original practice captures and may still show isolated lab addresses.
