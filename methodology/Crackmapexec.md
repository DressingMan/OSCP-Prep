
1. **SMB (Server Message Block)**:
   - SMB is a network file sharing protocol primarily used by Windows-based computers for sharing files, printers, and other resources.

2. **LDAP (Lightweight Directory Access Protocol)**:
   - LDAP is a protocol used for accessing and managing directory services, such as Active Directory, which is commonly found in Windows environments.

3. **RDP (Remote Desktop Protocol)**:
   - RDP is a proprietary protocol developed by Microsoft that allows users to remotely access and control Windows-based systems over a network connection.

4. **SSH (Secure Shell)**:
   - SSH is a cryptographic network protocol used for secure remote access to Unix-like operating systems.

5. **WinRM (Windows Remote Management)**:
   - WinRM is a Microsoft implementation of the WS-Management protocol that allows remote management of Windows-based systems.

6. **HTTP (Hypertext Transfer Protocol)**:
   - HTTP is the foundation of data communication for the World Wide Web and is used for transferring hypertext documents on the internet.

7. **SMB2/3**:
   - Updated versions of the SMB protocol used in modern Windows systems.

8. **MSSQL (Microsoft SQL Server)**:
   - MSSQL is a relational database management system developed by Microsoft.

9. **MySQL**:
   - MySQL is an open-source relational database management system.

10. **PostgreSQL**:
    - PostgreSQL is an open-source object-relational database system.

11. **Oracle**:
    - Oracle Database is a relational database management system developed by Oracle Corporation.

12. **VNC (Virtual Network Computing)**:
    - VNC is a graphical desktop sharing system that uses the Remote Frame Buffer (RFB) protocol to remotely control another computer.

13. **DNS (Domain Name System)**:
    - DNS is a hierarchical decentralized naming system for computers, services, or other resources connected to the Internet or a private network.

14. **DCE/RPC (Distributed Computing Environment / Remote Procedure Call)**:
    - DCE/RPC is a protocol used for communication between Windows systems and services.
